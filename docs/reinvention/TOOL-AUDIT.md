## Per-tool notes

### impeccable
Installed copy equals upstream 4.8.0 apart from 3 SKILL.md lines (path placeholder `<skill-base-dir>` vs `${CLAUDE_SKILL_DIR}`, a shorter description). Engine binary bundled at `scripts/bin/darwin-arm64/impeccable`, sha256 `543ee2f7…a9e1`, matching `engine-checksums.txt` in both copies. If missing, the launcher curls `https://github.com/pbakaus/impeccable/releases/download/engine-v0.1.18/<asset>` into `~/.impeccable/bin/` and verifies the hash. The plugin form (not what is installed) registers SessionStart, PostToolUse(Edit|Write) and Stop hooks running `impeccable hook`. `/impeccable hooks on` would write a project hook; this repo already has `.impeccable/hook.cache.json`, `design.json`, `surfaces/`, `review/`. Sub-commands: shape, init/teach, document, extract, critique, audit, polish, bolder, quieter, distill, harden, onboard, animate, colorize, typeset, layout, delight, overdrive, clarify, adapt, optimize, live, generate, plus hooks/doctor/pin. Persuade/Operate/Read/Experience are modes chosen per surface, not commands. Checklist: `skill-checklists/impeccable.md`.

### hallmark
`sloplint.mjs` is a zero-dependency Node 18+ static linter over .html/.css/.jsx/.tsx/.vue/.svelte/.astro (reads Tailwind class strings and cn/clsx/cva). No network in static mode, writes nothing (except `--before`, which writes `.hallmark/before.json`). `--url` (or `--render`) loads `sloplint-render.mjs`, which resolves puppeteer-core from cwd, the skill dir, `HALLMARK_PUPPETEER` or `npm root -g`, launches Chrome headless at widths 320-1920, and writes `.hallmark/shots/*.png` plus `.hallmark/.gitignore`. Exit 1 on any FAIL/REFLEX. Installed copy differs from upstream on one line: it skips any **top-level** path starting with `.`, so `sloplint.mjs .` scans nothing; pass `app components` instead. Gate 20 (missing Hallmark stamp) will always FAIL on this repo and should be ignored. Chrome launched inside the Seatbelt sandbox may fail; if so the render tier needs a sandbox-disabled run. Checklist: `skill-checklists/hallmark.md`.

### taste-skill
The plugin installed as "taste-skill" comes from **Leonxlnx/taste-skill**, not senlindesign. The senlindesign repo is a URL-to-design-DNA extractor (Playwright MCP, writes `./{domain}.md/.json`), with no LICENSE file despite the README badge. The installed plugin's `inspect.mjs` is zero-dependency, drives Chrome over CDP with a temp profile, measures headline line counts, sizes, fonts, colours, rules, shadows, gradients, contrast, overflow and frame balance at 1440/768/390, writes only to `--out`. Its house rules are the strictest of all the tools reviewed (no hairlines, no resting shadows, no gradients, no mono, at most 2 faces). Checklist: `skill-checklists/taste-skill.md`.

### scroll-craft
Prose rules are well quantified (motion durations, easing curve, scrim geometry, a 6-dimension uniqueness gate). `doctor.mjs` would execute ffmpeg, resolve playwright-core and read every `.env` up to 8 levels above cwd looking for `KIE_AI_API_KEY` (it only tests a regex and prints the path, not the value). With `--probe` it spends a paid API call. It was not run: project `.env*` reads are denied by the sandbox, and the harness blocked launching untrusted repo code. Nothing it checks matters unless we adopt the scroll-craft engine. `kie.mjs` uploads base64 files to a third-party host (`kieai.redpandaai.co`). Checklist: `skill-checklists/scroll-craft.md`.

### stop-design-slop
`Juuzoe/stop-design-slop` returns 404 and the account lists no public repos, so "removal tiers" could not be checked. The checklist uses arnunym/stop-design-slop instead and says so at the top. Most of that repo's sections are empty stubs; the usable parts are forms, dark patterns, AI-slop tells and onboarding. Checklist: `skill-checklists/stop-design-slop.md`.

### awwwards + jury
Rubric: Design 40%, Usability 30%, Creativity 20%, Content 10% (overall = weighted sum), plus six developer areas scored 1-10: Semantics/SEO, Animations/Transitions, Accessibility, WPO, Responsive, Markup/Meta-data. Every category starts at 6 and each point above needs cited evidence. Calibration: the blind critic ran about 1.1 below real juries on two Oct 2026 Sites of the Day. Bands: under 6.5, 6.5-7.1 Honorable Mention, 7.2+ SOTD. `/jury` needs Node 20+, Playwright and axe-core (both resolved from cwd, so this repo works with no installs), and a Chromium (bundled → cached `chromium-*` → channel chrome; here it falls back to the cached chromium-1248). It must score a production build (`next build && next start -p 4400`), not `next dev`. Writes only to `--out` and stdout. Crawl caps at 40 pages for audit and 8 page types for shots. Scoring has to be done by a fresh subagent that sees only the evidence. Checklist: `skill-checklists/awwwards-jury.md`.

### frontend-design
Installed plugin 1.1.1 SKILL.md is byte-identical to anthropics/skills@2c5958e. Prose only. Checklist: `skill-checklists/frontend-design.md`.

### ui-ux-pro-max
`npx ui-ux-pro-max-cli init --ai claude` (bin `uipro`; deps chalk, commander, ora, prompts; no postinstall) copies bundled templates into 7 folders under `./.claude/skills/` (ui-ux-pro-max with SKILL.md, `scripts/search.py` and data CSVs, plus banner-design, brand, design, design-system, slides, ui-styling) and deletes earlier ui-ux-pro-max layouts first (`removeLegacyInstall`). Flags: `-f`, `-o` (no-op), `-g` (`~/.claude/skills`), `-t <token>`, `--dry-run`. A GitHub release download path exists in code but no CLI flag reaches it, so the default install makes no network calls beyond npx. The bundled `design` skill calls the Gemini API (`GEMINI_API_KEY`) and `ui-styling` runs `npx shadcn@latest`. The skill runs a local Python BM25 search over style/palette/font CSVs. No telemetry found in `cli/src`. The README describes a Premium tier (brand/logo/asset generation, extended tokens) sold at uupm.cc; the open-source repo is the free tier. Only IA, token, mobile and a11y checks were extracted; style presets were deliberately skipped. Checklist: `skill-checklists/ui-ux-pro-max.md`.

### better-* (jakubkrehel/skills, plugin "interfaces")
Install: `npx skills add jakubkrehel/skills`, or `/plugin marketplace add jakubkrehel/skills` then `/plugin install interfaces@interfaces` (adds 15 skills; we need 7). The seven better-* skills are markdown only, with better-interface orchestrating the other six in order. Checklist: `skill-checklists/jakubkrehel-better.md`.

### web-interface-guidelines
The installed `web-design-guidelines` skill holds no rules of its own: each run it WebFetches `https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md`, so results follow whatever `main` holds that day (supply-chain drift; the pinned checklist is the stable copy). Upstream `install.sh` curls `command.md` into `~/.claude/commands/` and the config dirs of Amp, Cursor, OpenCode, Gemini and Antigravity, and appends to Windsurf's global rules. The README's `maximum-scale=1` suggestion contradicts its own never-disable-zoom rule, and it asks for Title Case where the other sources use sentence case. Checklist: `skill-checklists/web-interface-guidelines.md`.

### design-md-chrome
MV3 extension "DESIGN.md Style Extractor - TypeUI" 0.4.0. Permissions are narrow (`activeTab`, `scripting`, `storage`, `downloads`), with no host permissions and no persistent content scripts. Not installed and no checklist (out of scope for code review).
